# 🎨 بوت تحويل استكرات تليجرام إلى واتساب (Telegram to WhatsApp Sticker Bot)

بوت تليجرام متطور مبني باستخدام **Node.js** و **TypeScript** و **Telegraf** و **Sharp** و **FFmpeg**، يقوم بتحويل استكرات وحزم تليجرام بالكامل إلى استكرات متوافقة 100% مع تطبيق واتساب، وتصديرها بصيغة **`.wastickers`** (لإضافتها مباشرة بنقرة واحدة عبر تطبيق **Sticker Maker**) بالإضافة إلى ملفات **`.zip`** و **`.webp`**.

---

## ✨ المميزات الرئيسية

1. **دعم الاستكرات الفردية وحزم الاستكرات الكاملة:**
   - إرسال أي استكر مباشرة لتحويله فوراً.
   - إرسال رابط أي حزمة تليجرام (مثل `https://t.me/addstickers/Animals`) لتحويل الحزمة كاملة.
2. **مطابقة تامة لمعايير واتساب الرسمية:**
   - **المقاسات:** ضبط دقيق للأبعاد إلى **512×512 بكسل** مع حواف شفافة للحفاظ على النسبة الأصلية دون تشويه.
   - **الاستكرات الثابتة:** صيغة WebP بحجم أقل من **100 كيلوبايت**.
   - **استكرات الفيديو (WebM):** تحويل ومعالجة فيديو WebM (VP9) إلى استكر متحرك WebP بمعدل إطارات سلس ومدة لا تتجاوز 3 ثوانٍ وحجم أقل من **500 كيلوبايت**.
3. **تصدير بصيغة `.wastickers` الجاهزة لتطبيق Sticker Maker:**
   - تجميع تلقائي للحزمة مع توليد أيقونة الغلاف (`tray.png` بمقاس 96×96) وملفات التعريف (`title.txt`, `author.txt`).
   - يمكن للمستخدم فتح ملف `.wastickers` على الهاتف عبر تطبيق Sticker Maker والضغط على **"Add to WhatsApp"** مباشرة.
4. **شريط تقدم حي (Real-time Progress Bar):**
   - يوضح للمستخدم نسبة الإنجاز والتحويل أثناء معالجة الحزم الكبيرة.
5. **تنظيف تلقائي للملفات المؤقتة:**
   - لا يستهلك مساحة التخزين على الخادم بفضل الحذف الآمن للملفات بعد إرسالها.

## 🚀 طريقة التثبيت والتشغيل

### 1. استخراج توكن البوت (Bot Token):
1. افتح تطبيق تليجرام وابحث عن البوت الرسمي: **[@BotFather](https://t.me/BotFather)**.
2. أرسل الأمر `/newbot` واتبع التعليمات لاختيار اسم ويوزرنيم للبوت.
3. ستصلك رسالة تحتوي على الـ **HTTP API Token** الخاص ببوتك (مثال: `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`).

---

### 2. إعداد المتغيرات البيئية:
قم بإنشاء ملف `.env` (يمكنك نسخ `.env.example`):
```bash
cp .env.example .env
```
ثم افتح ملف `.env` وضع التوكن الخاص بك:
```env
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
```

---

### 3. تشغيل البوت:

#### وضع التطوير (Development):
```bash
npm run dev
```

#### فحص واختبار المعالجة (Verification Test):
```bash
npm test
```

#### وضع الإنتاج (Production):
```bash
npm run build
npm start
```

## ☁️ النشر والتشغيل على GitHub و Vercel

المشروع مُهيأ بالكامل للعمل على **Vercel Serverless** بنظام الـ **Webhook**:

### 1️⃣ رفع المشروع إلى GitHub:
1. توجه إلى [GitHub](https://github.com/new) وأنشئ مستودعاً جديداً (New Repository) وليكن باسم `tg-to-wa-sticker-bot`.
2. اربط المشروع وارفعه عبر الأوامر التالية من سطر الأوامر:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/tg-to-wa-sticker-bot.git
   git branch -M main
   git push -u origin main
   ```

### 2️⃣ ربط المشروع مع Vercel:
1. ادخل إلى حسابك في [Vercel](https://vercel.com) واضغط على **"Add New..." -> "Project"**.
2. اختر مستودع الـ GitHub الذي قمت برفعه (`tg-to-wa-sticker-bot`) واضغط **Import**.
3. في قسم **Environment Variables (المتغيرات البيئية)**، أضف المتغير التالي:
   - **Key:** `BOT_TOKEN`
   - **Value:** `8694545980:AAFTcq3XJYLWbSTQpZM1vNOFZBL9sBsdi4A` (توكن بوتك)
4. اضغط **Deploy**.

### 3️⃣ تفعيل الـ Webhook (خطوة واحدة فقط):
بمجرد انتهاء النشر، سيعطيك Vercel رابط المشروع (مثال: `https://tg-to-wa-sticker-bot.vercel.app`).
لتوجيه تليجرام لإرسال الرسائل إلى Vercel، نفّذ الأمر التالي في مجلد المشروع:
```bash
npm run set-webhook https://your-project-name.vercel.app
```
🎉 مبروك! أصبح البوت يعمل سحابياً 24/7 على Vercel مجاناً دون الحاجة لتشغيل جهازك.

*(إذا أردت إلغاء الـ Webhook مستقبلاً والعودة للتشغيل المحلي، نفّذ: `npm run set-webhook --delete`)*

## 📱 كيف يستخدم المستخدم الاستكرات في واتساب؟

### الطريقة الأولى: استيراد الحزمة كاملة بنقرة واحدة (موصى بها)
1. يقوم المستخدم بتثبيت تطبيق **Sticker Maker** (مجاني ومتوفر على Android و iPhone).
2. يرسل المستخدم رابط حزمة التليجرام للبوت.
3. يرسل البوت ملف الحزمة بصيغة `.wastickers`.
4. يضغط المستخدم على الملف ويختار **"فتح بواسطة / Open with" -> Sticker Maker**.
5. يضغط على زر **"Add to WhatsApp / إضافة إلى واتساب"**، وتظهر الحزمة في واتساب فوراً!

### الطريقة الثانية: الاستكرات الفردية
- عند إرسال استكر مفرد للبوت، يرسل البوت ملف `.webp` بالمقاس القياسي لواتساب (512×512) ويمكن إرساله أو حفظه كاستكر في واتساب ويب أو الجوال.
